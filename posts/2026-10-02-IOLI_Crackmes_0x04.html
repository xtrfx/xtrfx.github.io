To me it is not immediately obvious what is happening here, so I made an effort to clean this up, into a smaller though still messy psuedo-code version. After some steps we can begin to see that the user pin is treated as string where the individual characters are treated as single digit integers and are summed up to a total value (checkVal in my pseudo code.) If checkVal, the sum, is 15, that is treated as a success case.

The R2 tutorial cleans this up in much nicer way, but in principle we are able to see what is happening to the input and how it leads to a success condition.

I was a bit confused by the calls after the if conditional and asked for help from Claude, which provided some context to these lines:

eax = var_8h;              // eax = loop counter (0, 1, 2, ...)
rdx = (int64_t) eax;       // convert to 64-bit
rax = s;                   // rax = base address of string
rax += rdx;                // rax = s + offset (points to s[var_8h])
eax = *(rax);              // dereference: get the byte at that address
var_11h = al;              // store the character

In C, this is equivalent to:

var_11h = s[var_8h];
