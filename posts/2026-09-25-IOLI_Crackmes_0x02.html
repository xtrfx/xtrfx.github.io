The check against the pin takes place at 0x4011db, comparing values stored in EAX and EDX. In the instruction above, var_10h appears to be the user input string and thus the password must be stored in EDX. The value in EDX is computed starting with the instruction set starting at 0x4011b7. To help with clarity the IOLI tutorial suggests that a way to look at this code besides following the assembly is to look at decompiled interpretation of the code, using the 'pdc' command. Looking at both the assembly and C interpretation, we can see that two hex encoded values of 90 and 492 are added together and squared to generate a 6 digit pin of 338724 which is indeed the pin.
