I am working through a series of reversing challenges as a means of learning the use of Radare2 and to learn more about binary analysis. To that end, the Official Radare2 book, offers a walk through of several crackme challenges as means of introducing in practical terms the use of the tool suite. The IOLI challenges is a set of 10 challenges of which I found a 64 bit port. These are several years old , so little here is covering new ground, so mostly just a record of my working through them.

Initial Analysis

This is the first of the 10 challenges and the easiest. Upon execution of the binary we see: - Code execution triggers a password request - Failure triggers 'Invalid password!' string

A quick check of the file type and search for strings shows a likely candidate for a password, the 250382 string.

Looking through the binary we can see: - the 'password OK' string is in the .rodata section at address 0x402031 - that address is referenced by function main at address 0x40120b where the string is loaded into RDI for the subsequent call to puts followed by a jump to 0x401225 starting the end of the process - stepping back up the code to 0x4011ba we see where the user is prompted for the password - proper password is loaded into RSI by instruction at 0x4011f3 calling the virtual address of the password string at 0x0040202a

To better understand the logic flow of the comparison, I asked Claude for some clarification and this was the explanaiton.

***strcmp Return Value and Data Flow

strcmp returns an integer:

  • 0 if the strings are equal
  • < 0 (negative) if the first string is lexicographically less than the second

  • 0 (positive) if the first string is lexicographically greater than the second

***decision flow

call sym.imp.strcmp    ; Call strcmp, return value goes into rax (or eax on 32-bit)
mov <register>, eax    ; Move the return value to another register (or memory)
cmp <register>, 0      ; Compare that value against 0j<condition> <addr>    ; Jump based on the comparison (je, jne, jl, jg, etc.)

With this, I think I have a good sense of the logic and am ready to jump to the next challenge.
